# Sample Azure Speech Service

Ejemplo de uso de la API de Azure Speech Service para conversión de texto a voz y voz a texto.

Necesitaremos crear un recurso de Speech Service en el portal de Azure para obtener la clave y la región necesarias para autenticar las solicitudes.

Para ejecutar el ejemplo, sigue estos pasos:

[source,bash]
----
python3 -m venv .venv

source .venv/bin/activate

pip install -r requirements.txt

export SPEECH_KEY="your_key_here"

export SPEECH_REGION="your_region_here"

python3 sample-text-to-speech.py

python3 sample-speech-to-text.py
----
